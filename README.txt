GAME GALAXY E-COMMERCE WEBSITE

Files:
- index.html
- products.html
- cart.html
- checkout.html
- about.html
- contact.html
- style.css
- script.js
- assets/ (all product images)

How to run:
1. Keep all files and the assets folder together.
2. Open index.html in a web browser.
3. Use the navigation links to move between pages.

JavaScript features:
- Uses a for...of loop to display all products on products.html.
- Responsive product layout.
- Add to Cart buttons and localStorage cart persistence.
- Quantity and remove controls on cart.html.
- Contact form validation for required fields and email format.
- Checkout validation for shipping and payment fields.
- Coupon validation and percentage discounts:
    GALAXY10 = 10% off total order
    GAME15 = 15% off Game-category products

Important:
This is a classroom demonstration website only. It does not send contact messages or process real payments.
